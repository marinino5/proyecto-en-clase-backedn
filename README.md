ECOVOLT es una aplicación web desarrollada en Laravel para la consulta y gestión de una flota de vehículos de micromovilidad eléctrica.

El proyecto integra una experiencia pública para explorar los vehículos disponibles y un área administrativa protegida mediante autenticación para realizar la gestión interna de la flota.

---

## Descripción del proyecto

ECOVOLT fue desarrollado como parte de la asignatura **Backend** de la Universidad Autónoma de Bucaramanga - UNAB.

La aplicación implementa un sistema CRUD para la gestión de vehículos eléctricos, utilizando Laravel, Blade, Eloquent ORM, validación mediante Form Request y autenticación con Laravel Breeze.
